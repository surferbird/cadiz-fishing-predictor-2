CADIZ FISHING PREDICTOR 2.0

PWA móvil con identidad azul marino y turquesa.

FUNCIONES
- Motor heurístico interactivo por especie y condiciones introducidas manualmente.
- Ajustes de viento, oleaje, periodo, corriente, temperatura del agua, presión, tendencia, marea y franja horaria.
- Clasificación de especies y zonas candidatas.
- Perfil configurable de especies y radio.
- Diario de capturas guardado localmente y exportación CSV.
- Caché offline básica.

LIMITACIONES IMPORTANTES
- No hay conexión automática a AEMET, Puertos del Estado ni mareas.
- Las puntuaciones son reglas heurísticas experimentales, no probabilidades de captura ni un modelo entrenado.
- Las zonas son referencias generales; verifica restricciones portuarias, accesos, normativa, avisos y seguridad.
- Los datos del diario se almacenan en el navegador del dispositivo y no se sincronizan.

INSTALACIÓN
1. Publica los archivos en un hosting HTTPS (Netlify, GitHub Pages o servidor propio).
2. Abre la URL en Safari o Chrome móvil.
3. iPhone: Compartir > Añadir a pantalla de inicio.
4. Android: menú de Chrome > Instalar aplicación.

Para uso real, el service worker requiere HTTPS (salvo localhost).
